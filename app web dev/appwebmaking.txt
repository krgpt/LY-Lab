AI 기술 활용 앱 및 웹 개발 8주 입문 과정 예시

[과정 개요]

* 수업 목표: AI 에이전트를 조율하는 능력을 키워 8주 동안 나만의 웹 사이트 및 iOS/Android 앱 서비스를 구현하고 실제 배포
* 대상: 코딩 경험이 적은 초보자, 기획자, 디자이너, 1인 창업 희망자
* 핵심 기술 스택
* AI 및 IDE 툴: Cursor AI, v0.dev, Claude / ChatGPT
* 프론트엔드 및 모바일: React / React Native (Expo) - 한 번 작성하여 웹과 모바일 앱 모두 대응
* 백엔드 및 DB: Supabase (데이터베이스 및 로그인 구현)
* 배포: Vercel (웹 배포), EAS (앱 빌드 및 테스트)

[8주 상세 커리큘럼]

1단계: AI 바이브 코딩 입문 및 UI 설계 (1~2주차)

1주차: AI 시대의 개발 방식 및 환경 구축

* AI 코딩 스택의 이해 (LLM, AI 코딩 에이전트의 작동 원리와 한계)
* 개발 환경 구축: Cursor 에디터 설치, Extension 및 AI Model 설정
* 실습: Cursor의 Edit/Chat/Composer 모드를 활용해 간단한 랜딩 페이지 만들기

2주차: v0 및 AI를 활용한 UI/UX 고속 프로토타이핑

* v0.dev를 활용한 텍스트 기반 UI 컴포넌트 자동 생성
* 생성된 UI 코드를 Cursor로 가져와 내 프로젝트에 통합하기
* 실습: 반응형 웹 UI 레이아웃 완성 및 간단한 상태 데이터 연동

2단계: 백엔드 연동 및 웹 애플리케이션 완성 (3~4주차)

3주차: Supabase를 이용한 백엔드 및 데이터베이스 구성

* DB 기초 개념과 BaaS(Backend as a Service)의 이해
* AI 프롬프트를 이용해 데이터베이스 테이블 구조 자동 생성
* 회원가입 / 로그인(Auth) 기능 구현
* 실습: Supabase 연동을 통한 회원 관리 및 데이터 생성, 조회, 수정, 삭제 연동

4주차: 웹 풀스택 프로젝트 완성과 배포

* AI를 활용한 비즈니스 로직 구현 및 버그 디버깅
* Vercel을 이용한 커스텀 도메인 웹 사이트 1분 만에 배포하기
* 실습: 나만의 웹 서비스 라이브 배포 완료

3단계: 웹에서 모바일 앱(iOS/Android)으로 확장 (5~6주차)

5주차: React Native (Expo)를 이용한 크로스플랫폼 앱 입문

* 웹 코드를 모바일 앱으로 전환하는 전략 (React Native & Expo 기본)
* 모바일 고유 UX/UI 컴포넌트 다루기 (네비게이션, 터치 이벤트, 탭 바 등)
* 실습: Cursor AI의 도움을 받아 기존 웹 프로젝트를 Expo 앱 프로젝트로 변환 및 스마트폰 실기기 테스트

6주차: 스마트폰 네이티브 기능 연동

* AI의 안내에 따라 모바일 하드웨어 기능 제어하기
* 카메라, 갤러리 접근, 위치 데이터(GPS), Push 알림 기능 구현
* 실습: 사진 업로드 및 위치 기반 데이터를 활용하는 모바일 앱 기능 완성

4단계: 프로젝트 고도화 및 앱 스토어 출시 준비 (7~8주차)

7주차: 프로젝트 고도화 및 AI 디버깅 노하우

* .cursorrules 파일 설정을 통한 프로젝트 맞춤형 AI 성능 최적화
* 오작동 코드 해결 및 AI 프롬프트 재작성 기법
* 모바일 화면 크기 반응형 최종 점검 및 디자인 디테일 다듬기

8주차: 앱 빌드, 스토어 제출 준비 및 캡스톤 발표

* Android 및 iOS 앱 빌드 과정 이해 (EAS Build)
* Google Play Store 및 Apple App Store 등록 절차 및 가이드라인 학습
* 실습: 최종 캡스톤 프로젝트 발표 및 피드백, 지속적인 개발 학습 로드맵 제안
